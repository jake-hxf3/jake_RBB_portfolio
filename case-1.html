Case Study - Squeezit Street Juice

  • Squeezit was a defunct juice brand from the 90s. Now it's no longer remembered
  • Or is it? With the help from my development magic, Squeezit returns from the grave as a hero.
  • This inspires me to create a website with a very heroic look

Problem

  • This is my final project for the last term's design program

Deliverables

  • Three pages of the promotional website
  • Responsive layouts using a provided grid system
  • At least three interactions on the web pages using Javascript

Goals

  • To meet the Deliverables
  • To utilize the brand identity I established in the other courses
  • To represent my design aesthetics

Visions

  • Squeezit had a target audience of adolescents, so I oriented the designs toward a youngster/skateboarding culture
  • The hero image should appear glorious, considering that it is literally the hero brand.
  • The symbolization would be the excruciating skateboards, and the wavy shapes of the skateparks. These will be the outlines for the page sections

Process

To create the wavy shapes of the sections, I think of two ways

  • Using clipping mask (the mask property)
  • Using pseudoelements ::before and ::after to mimick the shapes
